My website is about Avatar The Last Airbender characters and tips from the each of them on how one can improve themselves. It has a navigation bar at the top and includes Aang, Toph, Zuko, Katara
Sokka and Suki. When you click on each of the characters, it directs you to a page and demonstrates some affirmations, recipes and hobbies related to each character that you can implement 
in your daily routine. There us a go back button at the end so that you can be taken back to the navigation menu.
